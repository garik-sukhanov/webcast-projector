# Проектор WebCast

Android-приложение со встроенным браузером, страница которого выводится на
**Miracast-проектор** как на второй экран. Показ живёт в фоновом сервисе и
продолжается, даже когда приложение свёрнуто. Плавающая кнопка «ТВ» поверх
всех приложений затемняет планшет одним тапом.

## Как пользоваться

1. **① Подключить проектор** → в системном окне выберите проектор
   (на Samsung — Smart View, в остальных «Трансляция»). Статус сменится на
   «Проектор найден: …».
2. Откройте страницу с видео (адрес сверху). На старте есть кнопки
   «Тестовое видео» для проверки.
3. **② На проектор ▶** — страница с видео уедет на проектор.
4. Затемнить планшет: **◑ Затемнить** в приложении **или** плавающая кнопка
   **«ТВ»** (работает и поверх других приложений). Выход из затемнения —
   **долгое нажатие** по чёрному экрану. Долгое нажатие по кнопке «ТВ» —
   полностью остановить показ.
5. **⏹ Стоп** — завершить показ.

## Что важно понимать про Miracast

- **Приложение не может само включить Miracast** — в Android нет публичного
  API. Кнопка «① Подключить проектор» открывает системное окно трансляции,
  проектор выбирается вручную.
- **Полностью погасить экран планшета нельзя** — это ограничение Miracast.
  «Затемнить» = чёрный оверлей + минимальная яркость + запрет засыпания.
  Видео на проекторе при этом идёт, потому что рисуется на второй экран
  независимо (`Presentation`).
- **Видео должно быть открыто в этом приложении.** Захватить чужое приложение
  (например клиент YouTube) и при этом гасить планшет технически нельзя —
  это уже screen capture.
- **YouTube** в WebView обычно не проигрывается. Надёжнее прямые ссылки на
  файлы (mp4/mkv) и онлайн-плееры на HTML5.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET` | загрузка страниц |
| Поверх других приложений (`SYSTEM_ALERT_WINDOW`) | плавающая кнопка и затемнение; приложение попросит его при первом «② На проектор» |
| Уведомления | постоянное уведомление сервиса показа (Android 13+) |
| Foreground service `mediaPlayback` | чтобы показ не убивался в фоне |

## Сборка

Нужны JDK 17+ и Android SDK (platform android-35, build-tools 35+).

**Android Studio:** открыть папку → Gradle sync → **Run ▶** на планшете или
**Build → Build APK(s)**.

**Терминал:**

```bash
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Если Gradle не находит SDK, создайте `local.properties` (в репозиторий он не
попадает) с путём к нему:

```
sdk.dir=/путь/к/Android/sdk
```

## Проверка без реального проектора

Для разработки можно включить симуляцию второго экрана и прогнать показ:

```bash
adb shell settings put global overlay_display_devices "1280x720/213"   # включить
# ... протестировать «На проектор» ...
adb shell settings delete global overlay_display_devices               # выключить
```

## Как устроено

| Класс | Зачем |
|---|---|
| `MainActivity` | браузер на планшете и управление |
| `ProjectionService` | foreground-сервис: показ на проекторе, плавающая кнопка, затемнение |
| `BrowserPresentation` | контент второго экрана — свой `WebView` в контексте дисплея; это лечит «белый экран» (переносить один `WebView` между экранами нельзя) |
